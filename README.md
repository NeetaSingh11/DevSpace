# 🚀 DevSpace

A modern collaborative project management platform built using the **MERN Stack**.

---

## ✨ Features

- 🔐 JWT Authentication
- 👥 Workspace Management
- 📂 Project Management
- ✅ Task Management
- 📅 Due Dates
- 📎 File Attachments
- 📊 Dashboard Analytics
- 📈 Charts & Statistics
- 📋 Kanban Board
- 👤 Role Based Access Control
- 📨 Workspace Invitations
- 🔍 Search Functionality
- 📝 Activity Timeline
- 🔔 Toast Notifications
- 📱 Responsive UI

---

## 🛠 Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Axios
- React Router
- Recharts
- React Hot Toast

### Backend
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- JWT Authentication
- Multer

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/NeetaSingh11/DevSpace.git
```

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

---

## 🔑 Environment Variables

Create a `.env` file inside the backend folder.

```env
PORT=5000
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
```
